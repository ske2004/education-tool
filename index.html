1. C++17 / Sokol 3D Editor & STEM Quest

Create buildings, castles, bridges, roads, rivers, trees, animals, NPCs, items, and 18 procedural prop types. Press Q / E to cycle NPC, Item, and Prop presets, or click Sample to play the built-in Solar Observatory STEM restoration quest. 

# Launch the interactive 3D editor or WebAssembly build
./bin/debug/catedu
./bin/debug/catedu --export-gltf assets/world.glb

# Or run the automated headless verification suite
python3 build.py test

2. Headless Agent Server & Python Town SDK

Run catedu --agent-server for a zero-GUI simulation server speaking line-delimited JSON over stdin/stdout with A* road/bridge pathfinding, spatial observation queries, and instant .glb / .dat snapshots. 

{"op": "spawn", "name": "Ada", "x": 4, "y": 2}
{"op": "observe", "agent": 1, "radius": 14}
{"op": "go", "agent": 1, "x": 12, "y": 8}
